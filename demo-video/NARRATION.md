# Hermes demo video: narration script

Video: `Hermes-demo.mp4`, 1:55, 1920x1080. It has burned-in captions and a silent audio track, so it works as is or with a voiceover.
To add your voice, play the video, read each line when its timestamp comes up, then put the recording on the video's audio track in any editor (iMovie, Clipchamp, CapCut, Riverside). About 2.5 words per second fits the timing.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00 | Title | This is Hermes, a skill exchange for students. |
| 0:04 | The problem | Every student knows something another student wants to learn. But there's no easy, safe way to find that person, agree on a time, or see whether anyone actually learned something. |
| 0:11 | Discover | Discover ranks partners by what you can trade. Maya teaches guitar and wants to learn Java, which I teach. It also finds free time we share, even across time zones. |
| 0:25 | Introduce yourself | Every connection starts with an introduction, so nobody gets a cold booking from a stranger. |
| 0:31 | Maya's side | The demo switcher lets me show the other side. Maya reads my introduction, accepts, and replies. |
| 0:43 | Plan a session | Back as Eric, I see her unread message and plan a session. One click fills in a time we're both free, and I set my goal and how we split the teaching. |
| 1:00 | Maya accepts | Maya accepts the request, and it moves to upcoming meetings for both of us. |
| 1:08 | Practice | In a skill exchange, the timer tells each person whose turn it is. Halfway through, it switches who's teaching. |
| 1:18 | Learning record | Afterward, each learner records confidence before and after, the result of an independent task, and what to practice next. |
| 1:29 | Progress | The Progress page measures learning, not just minutes: goals achieved, confidence change, and a practice-next list. |
| 1:36 | Feedback | Partners only see the feedback that was shared with them. The rest of the journal stays private. |
| 1:42 | Next steps | Next, I'm adding real accounts and a shared database, live chat and video between devices, a shared whiteboard, and follow-up sessions built from each practice-next step. Right now it's a working prototype that keeps data in one browser. |
| 1:51 | Closing | Hermes. A little help goes both ways. |
